# Declaración de uso de inteligencia artificial

## Herramienta utilizada

Se utilizó GitHub Copilot en Visual Studio Code como asistente de inteligencia artificial durante el desarrollo y la preparación de la documentación de Rama.

## Uso en este proyecto

La herramienta apoyó al equipo en las siguientes tareas:

- Revisar la rúbrica y compararla con las funciones y la documentación existentes.
- Proponer, implementar y explicar la persistencia local de solicitudes y cuentas mediante JSON.
- Incorporar notificaciones visibles dentro de la aplicación y la consulta de configuración remota con valores predeterminados para el modo sin conexión.
- Preparar pruebas automatizadas para la persistencia, la configuración remota y los cambios de estado.
- Redactar y organizar documentación de instalación, decisiones técnicas, límites, pruebas y preparación para la demostración.

## Revisión y responsabilidad del equipo

La IA se utilizó como apoyo, no como sustituto del análisis, las decisiones ni la defensa del equipo. Las propuestas se contrastaron con el código del proyecto y se verificaron con pruebas automatizadas. El equipo debe revisar el código y esta declaración, adaptar su contenido para que refleje fielmente el uso realizado por todas las personas integrantes y ser capaz de explicar cada decisión técnica durante la defensa.

Las pruebas automatizadas no equivalen a una validación con usuarios ni con el socio comunitario. Las cuentas, direcciones y solicitudes de ejemplo de la aplicación son datos de demostración; no son resultados de entrevistas ni evidencia de participantes reales. El equipo debe obtener y presentar por separado cualquier validación o retroalimentación real que haya realizado, con autorización y sin inventar resultados.

La responsabilidad por el código, los datos, las pruebas, las decisiones de diseño y la presentación final corresponde al equipo.
